# 课程解剖参考图工作台

目标：在既有 Three.js 图谱旁增加乙方素材入口，复用完整肌肉和骨骼模型。

1. 新建 references/，保留原图谱；十课预设按肌肉真实名称映射，搜索与手动选择允许乙方自由取图。
2. 背景肌肉默认完整不透明；目标黄色高亮。允许背景透明查看深层，支持骨骼开关和前后侧相机定位。
3. 导出 2048/4096 像素 PNG，透明或白底；与署名文件分开，画面无文字。
4. 浏览器验证实际 GLB 加载、非空肌群映射、PNG 尺寸与 alpha、手机布局，以及旧入口。
5. 提交独立分支并创建 PR；准备全资源静态 ZIP。国内部署依赖用户指定托管账号，未经国内网络测试不宣称国内可达。
